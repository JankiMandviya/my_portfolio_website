Measured results and scope

The agentic workflow reached approximately 80–85% RCA performance on an evolving internal evaluation of 10–15 OpenTitan bugs, including complex bugs and live regression failures. Tested complex investigations took approximately 10–15 minutes. These results describe this evaluation set.

For one complex bug, a design-verification engineer identified the cause in one day. The agent investigated the same bug in 15–20 minutes, and the engineer checked its result. These timings describe this case only.

Moving away from repository-wide graph construction removed a setup stage previously taking approximately 30–60 minutes. Specification processing and tool execution remain separate costs.

The problem

Verification failures require connecting logs, specifications and source code. Relevant evidence can be spread across a large repository.

The first approach

I designed AST-based code graphs with Kuzu and constrained Cypher query templates to support bug classification and localization.

What broke down

Seed selection proved brittle. Noisy retrieval increased context size, while repository-wide graph construction added setup and resource costs.

The architectural shift

I moved toward a LangGraph investigation workflow that selects evidence as hypotheses evolve, removing the upfront repository graph requirement.

Reliability mechanisms

Constrained search and file-inspection tools, investigation notes, hypothesis tracking, and separation of reasoning, execution and reporting.

The tradeoff

Adaptive investigation gives greater flexibility, but makes tool reliability, stopping conditions, context selection and model cost central design concerns.

High-level account of my contributions and measured internal evaluation results. No proprietary source code is included.

Model results

The custom activity-classification network achieved 98% accuracy using MoveNet keypoints. Fine-tuning YOLOv8 on a custom dataset delivered a measured 14% improvement in object detection.

These are results from the respective project evaluations. The 14% figure preserves the recorded improvement; it is not reinterpreted as mAP or a percentage-point gain. The earlier 98.97% LRCN test accuracy belongs to a separate internship video-classification project.

One integrated workflow

Human activity recognition, object detection, face recognition and drowsiness detection share an edge deployment and a timestamped monitoring workflow.

Representations that fit the task

MoveNet keypoints provide a compact pose representation for activity classification. YOLOv8 handles custom object detection; dlib and MediaPipe support identity and drowsiness features.

Beyond model inference

I worked on RTSP and WebRTC streaming and logs connecting activity, individual identity and detected objects with timestamps.

Engineering lesson

A useful vision application needs more than individual model results. Integration, edge resource constraints and the path from video input to observable events shape the whole system.
