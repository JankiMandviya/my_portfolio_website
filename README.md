# Janki Mandviya | AI/ML engineering portfolio

Personal portfolio built with HTML, Tailwind CSS and vanilla JavaScript.

Edit the content in `src/index.html` and styling in `src/styles.css`. Run `npm ci`, then `npm run build && npm run check` for the preview checks. To build for Pages, run `node scripts/build.mjs --public`; the static output is in `dist/`.

With Settings → Pages → Source set to **GitHub Actions**, pushes to `main` build and deploy the portfolio.
